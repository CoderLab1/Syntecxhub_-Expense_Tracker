# SyntecxHub – Expense Tracker

A simple and responsive **Expense Tracker Application** built using HTML, CSS, and JavaScript.  
It helps users track daily expenses, categorize them, and view totals in real-time.

---

## 🚀 Features

- Add new expenses with amount, title, and date  
- Delete any expense entry  
- Real-time total calculation  
- Clean and responsive UI  
- Fully client-side (no backend required)  
- LocalStorage support (if implemented)

---

## 🛠️ Tech Stack

- **HTML5**  
- **CSS3**  
- **JavaScript (ES6+)**  
- **LocalStorage** (optional)  
- **Git & GitHub**
